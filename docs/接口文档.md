# 接口文档

> **何时查看**：新增/修改 API 端点时 / 前端对接接口时 / 排查 40xxx 错误码时 / 了解请求参数和响应格式时

本文档列出打印模板中心已实现的后端 API 接口。

## 基础信息

Base URL：

```text
/api/v1
```

统一响应格式：

```json
{
  "code": 0,
  "message": "success",
  "data": {}
}
```

下载类接口例外：
- `GET /business-data/template/:bizType` 返回 Excel 文件，不包裹统一 JSON。
- `POST /print/pdf` 返回 PDF 文件，不包裹统一 JSON。

错误码：

```text
40000 参数错误 / 用户名或密码错误
40001 编码重复（模板/模块/字段）
40002 引用冲突 / DSL 校验失败 / 必填字段不允许删除
40003 模板名称重复
40004 模板未启用
40005 模板类型不匹配
40006 打印份数超限 / 总页数超限
40100 未登录 / 登录已过期（需重新登录）
40300 无权限访问该接口
40400 数据不存在
50000 系统异常
```

## 模板管理

```text
GET    /templates                    获取模板列表
POST   /templates                    创建模板
GET    /templates/:id                获取模板详情
PUT    /templates/:id                更新模板（全量）
PATCH  /templates/:id/name           更新模板名称
POST   /templates/:id/design-log     记录设计日志
POST   /templates/:id/enable         启用模板
POST   /templates/:id/disable        停用模板
POST   /templates/:id/copy           复制模板
DELETE /templates/:id                删除模板
POST   /templates/status             批量更新模板状态
```

模板列表查询参数：

| 参数 | 说明 |
|------|------|
| `name` | 模板名称模糊查询 |
| `type` | 模板类型（LOCATION/CONTAINER/PRODUCT/自定义模块编码） |
| `status` | 模板状态（enabled/disabled） |
| `page` | 页码 |
| `pageSize` | 每页条数，后端最大 200 |

## 字段字典

```text
GET    /template/fields/:moduleCode    获取字段字典
```

模块类型（大写）：

- `LOCATION` — 库位字段
- `CONTAINER` — 容器字段
- `PRODUCT` — 商品字段
- 自定义模块编码

## 业务模块

```text
GET    /business-modules                                  获取业务模块列表
POST   /business-modules                                  创建业务模块
PUT    /business-modules/:moduleCode                      更新业务模块
DELETE /business-modules/:moduleCode                      删除业务模块
POST   /business-modules/:templateType/fields             新增字段（⚠️ 参数名为 :templateType，不是 :moduleCode）
PUT    /business-modules/:templateType/fields/:fieldCode  更新字段
POST   /business-modules/:templateType/fields/:fieldCode/disable  停用字段
POST   /business-modules/:templateType/fields/:fieldCode/enable   启用字段
DELETE /business-modules/:templateType/fields/:fieldCode  删除字段
```

模块响应字段：

```json
{
  "code": "LOCATION",
  "name": "库位",
  "templateLabel": "库位模板",
  "dataLabel": "库位数据",
  "codeField": "locationCode",
  "recordCodeField": "locationCode",
  "storageMode": "json_table"
}
```

系统内置 LOCATION / CONTAINER / PRODUCT 不可删除。

## 业务数据

所有业务数据统一存储在 `business_record` 表，字段 schema 由运行时动态编译。

```text
GET    /business-data/types                              获取业务类型列表
GET    /business-data/search                             搜索业务数据
POST   /business-data                                    新增业务数据
PUT    /business-data/:bizType/:bizCode                  更新业务数据
DELETE /business-data/:bizType/:bizCode                  删除业务数据
DELETE /business-data/batch/:bizType                     批量删除业务数据
GET    /business-data/template/:bizType                  下载导入模版
POST   /business-data/import/:bizType                    导入业务数据
```

业务类型 `bizType` 即 `module_code`。

### 更新/删除精确定位

更新和单条删除接口支持请求体传入 `_dbId`（数据库主键），用于精确定位行。当同编码存在多条记录时，`_dbId` 可确保只操作目标行；不传 `_dbId` 时按编码匹配（兼容旧调用）。

```json
// PUT /business-data/LOCATION/KW-001
{ "fields": { "locationCode": "KW-001-NEW" }, "_dbId": 5 }
```

### 批量删除

批量删除接口 `DELETE /business-data/batch/:bizType` 请求体传 `ids` 数组（数据库主键 `_dbId` 列表），不再按编码删除：

```json
// DELETE /business-data/batch/LOCATION
{ "ids": [5, 6, 7] }
```

### 导入行为

导入逐行调用创建接口：
- 重复编码：允许（003 迁移已移除 DB 唯一约束），编码字段默认不在唯一性校验范围内
- `is_unique` 字段：重复组合的行报错跳过，不影响其他行
- 上传接口使用 `multipart/form-data`，文件字段名为 `file`
- 仅支持 `.xlsx` 文件，后端上传大小限制为 5MB

### 搜索参数

| 参数 | 说明 |
|------|------|
| `bizType` | 业务类型（LOCATION/CONTAINER/PRODUCT/自定义模块编码） |
| `keyword` | 业务编码关键字，支持逗号或空格分隔批量查询（模糊匹配 record_code + search_text） |
| `fieldFilters` | 按字段精确查询，JSON 对象格式，如 `{"warehouseCode":"DE","areaCode":"DE-1"}`，仅对启用了查询的字段生效 |
| `page` | 页码 |
| `pageSize` | 每页条数，后端最大 200 |
| `sortField` | 排序字段 |
| `sortDir` | 排序方向（ASC/DESC） |

## 字段属性说明

字段字典（`GET /template/fields/:moduleCode`）返回的字段属性：

| 属性 | 说明 |
|------|------|
| `code` | 字段编码 |
| `name` | 字段中文名称 |
| `type` | 字段类型（string/number/integer/date/select） |
| `required` | 是否必填 |
| `searchable` | 是否启用查询（true=在业务数据中可按该字段精确查询） |
| `sortable` | 是否支持排序 |
| `enabled` | 是否启用 |
| `isUnique` | 是否要求值唯一（004 迁移新增，默认 false）。新增/编辑/导入时后端通过事务行锁校验 |
| `example` | 示例值 |
| `desc` | 字段说明 |
| `sortNo` | 排序号（必填） |

业务编码字段（主键）默认 `searchable=true` 且不可取消。

## 打印

```text
POST   /print/pdf                    生成并下载打印 PDF
GET    /print/last-template           获取用户上次使用的打印模板
```

`POST /print/pdf` 请求体：

| 字段 | 说明 |
|------|------|
| `templateId` | 模板 ID，必填 |
| `businessType` | 业务类型编码，需与模板类型一致 |
| `rows` | 要打印的业务数据数组，必填且不能为空 |
| `copies` | 打印份数，1-1000 |
| `businessNo` | 可选，打印日志中的业务编码摘要；不传时由 rows 自动拼接 |
| `warehouseCode` | 可选，打印日志中的区域仓编码 |

限制：
- `copies` 不能超过 1000
- `rows.length * copies` 不能超过 200000 页
- PDF 采用流式输出，响应头包含 `Content-Type: application/pdf` 和 `X-Print-Log-Id`

### 获取上次模板

GET /print/last-template?businessType=LOCATION

参数 `businessType` 为业务类型编码（LOCATION/CONTAINER/PRODUCT/自定义模块编码），返回 `{ templateId }`。
