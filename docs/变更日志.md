# 变更日志

## [未发布] — 当前开发版本 (2026-07-03)

### 业务数据编辑增强
- 编辑弹窗编码字段不再禁用，支持修改业务编码
- 修改编码后自动更新 `record_code`，唯一性校验通过事务锁保障
- 编辑/删除改为 DB 主键 `_dbId` 精确定位行，支持同编码多条记录独立操作

### 导入功能
- 导入支持重复编码（003 迁移后无 DB 唯一约束）
- 导入时 `is_unique` 字段校验生效：重复组合的行失败但不影响其他行

### 打印功能增强
- 打印份数上限从 99 → 1000，超出报错拦截（不再静默截断）
- 前端实时校验份数范围，后端双重校验，非法值即时提示
- PDF 生成从内存缓冲改为流式输出（`doc.pipe(res)`），大份数打印内存不爆炸
- 极端场景总页数校验（200,000 页上限），防止 100条×2000份 等组合导致服务器崩溃
- 打印请求超时从默认 2 分钟延长到 30 分钟

### 业务数据修复与优化
- **字段值为空时不再显示 `[字段名]` 占位符**：修复 `pdfGenerator.js` 中 `renderText`/`renderBarcode`/`renderQrcode` 的字段值 fallback 逻辑
- **批量查询结果不一致修复**：批量搜索（逗号/空格分隔）从 `record_code IN (...)` 精确匹配改为与单条一致的 `LIKE` 模糊匹配 + `search_text` 双字段搜索
- **删除改为按 DB 主键 ID**：从按编码删除改为按选中行的数据库 ID 精确删除，避免编码维度的误删
- 删除/打印的选中数量统计改为基于 DB 主键 `_dbId`，`row-key` 去重问题彻底修复

### 唯一性校验重构
- `recordService` 新增 `withUniqueGuard`：创建/编辑记录时用 MySQL 事务 + `SELECT FOR UPDATE` 行锁消除并发竞态条件
- `compileSchema` 增加容错：主编码字段不存在时自动回退到唯一字段或首个字段，不再 500 崩溃
- LOCATION 模块 `locationCode` 字段被意外禁用问题已修复并恢复
- 前端禁止停用/删除主编码字段，后端 `fieldService` 增加 `assertNotRecordCodeField` 保护

### 前端优化
- Ant Design Vue 从全量引入改为按需引入（仅注册 25 个实际使用的组件），减小打包体积
- Vite 构建配置新增 `manualChunks`，拆包 `ant-design` / `vue-vendor`
- 模板预览样式计算提取为独立 `templatePreviewStyleService.js`
- 删除未使用的 `printRotationService.js`
- 清理多处死代码（`findParent`、`onPageChange`、`selectElement`、`deleteBusinessData` 等）
- `FieldDictionary.vue` 弹窗支持鼠标拖拽移动（`composables/useDragModal.js`）
- 新增 `npm test` 脚本

### 测试与文档
- `api.test.js` 新增全局 `after()` 钩子自动清理测试数据，不再污染开发数据库
- 测试用例更新：`deleteRecords` 改为 DB ID 校验、`disableField` 改为主编码防护校验
- `AGENTS.md` §2.2 补充遗漏的测试数据清理表范围 + "禁止修改既有本地数据"条款
- `docs/测试指南.md` 新增"测试数据清理"章节（影响范围、自动/手动清理方式）
- 校正文档中过期描述：打印入口、打印份数上限、`print_log.business_no` 类型、`search_text` 搜索行为、本地启动说明和接口下载响应说明
- 修正迁移脚本、Docker 数据库连接用户和前端打印份数输入框上限，保持代码与文档一致
- 新增 `docs/故障排查手册.md` 和 `docs/数据导入规范.md`，集中说明高频排障和 Excel 导入规则

### 数据库迁移
- `003_drop_business_record_unique.sql` — 移除 `business_record` 表的 `uk_module_record` 唯一约束，允许同一模块内导入重复编码的业务数据
- `004_add_field_unique.sql` — `print_field_dict` 表新增 `is_unique` 列，支持字段级唯一性校验
- `005_expand_print_log_business_no.sql` — 将 `print_log.business_no` 从 `VARCHAR(128)` 扩大为 `TEXT`，解决批量打印时编码拼接超长报错问题；后端同步调整截断阈值至 2048 字符

## [1.0] — 首个完整功能版本

### 模板管理
- 模板列表（CRUD + 批量启用/停用 + 复制 + 搜索）
- 可视化模板设计器（拖拽组件：文本/横线/矩形/一维码/二维码/复选框）
- 模板属性编辑、字段绑定、撤销重做、复制粘贴
- 模板启用/停用校验（未绑定字段/元素超出画布等检查）

### 字段字典
- 树形分类（库位/容器/商品 + 自定义模块）
- 字段 CRUD + 启用/停用
- 启用查询开关（控制业务数据搜索区字段）

### 业务数据管理
- 统一 `business_record` 表存储（JSON字段）
- 查询（编码批量查询 + 字段精确筛选）
- CRUD + 批量删除 + Excel 导入/导出模板

### 打印功能
- 选择模板 + 数据 → 生成 PDF 下载
- 条码（bwip-js）+ 二维码（qrcode）生成
- PDFKit 中文支持（ArialUnicode 字体）
- 打印日志记录
- 记忆用户上次使用的打印模板

### 权限系统（RBAC）
- 五表模型：sys_user / sys_role / sys_menu / sys_user_role / sys_role_menu
- JWT 登录（24h过期）
- 前端：路由守卫 + v-permission 指令
- 后端：requirePermission 中间件
- 菜单管理（目录/页面/按钮三级）
- 角色权限卡片式分配
- 空目录自动隐藏

### 系统预置
- 3个业务模块：库位(LOCATION) / 容器(CONTAINER) / 商品(PRODUCT)
- 3个预置模板：库位标签-100x50 / 容器入库标签-100x50 / 拣货容器标签-100x150
- 2个预置账号：admin / business
- 14个库位字段 + 3个容器字段 + 3个商品字段

### 部署
- Docker Compose 编排（MySQL + Backend + Frontend + Nginx）
- Nginx HTTPS 反向代理
- Let's Encrypt 证书自动续期
- 阿里云 ECS 一键部署脚本
- 预提交检查脚本
